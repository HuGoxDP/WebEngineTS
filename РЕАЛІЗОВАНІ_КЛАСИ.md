# 📋 Список реалізованих класів WebEngineTS

## 🎯 CORE - Ядро двигуна

### Базові класи
- **`EngineObject`** - Базовий клас для всіх об'єктів двигуна (GameObject, Component, Assets)
  - Забезпечує унікальний UUID та базову ідентифікацію
  - Методи: `exists()`, `destroyImmediate()`, `static destroy()`

- **`Component`** - Базовий клас для всього, що прикріпляється до GameObject
  - Посилання на GameObject та Transform
  - Методи: `getComponent<T>()`, `getComponents<T>()`, `addComponent<T>()`

- **`Behaviour`** - Компонент з можливістю увімкнення/вимкнення
  - Методи: `onAwake()`, `enabled` (getter/setter)

- **`ScriptableBehaviour`** - Базовий клас для користувацьких скриптів
  - Життєвий цикл: `awake()`, `start()`, `update()`, `lateUpdate()`, `fixedUpdate()`, `onDestroy()`

### GameObject та трансформації
- **`GameObject`** - Основна сутність сцени, контейнер для компонентів
  - Методи: `addComponent<T>()`, `getComponent<T>()`, `getComponents<T>()`, `removeComponent<T>()`
  - Властивості: `name`, `tag`, `layer`, `activeSelf`, `activeInHierarchy`

- **`Transform`** - Компонент, що визначає позицію, поворот та масштаб
  - Методи: `translate()`, `rotate()`, `rotateAround()`, `lookAt()`
  - Властивості: `position`, `rotation`, `scale`, `localPosition`, `localRotation`, `localScale`
  - Ієрархія: `parent`, `children`

### Управління сценами та часом
- **`Scene`** - Контейнер для ігрових об'єктів
  - Методи: `addGameObject()`, `removeGameObject()`, `findGameObjectWithTag()`, `findGameObjectWithName()`, `destroy()`

- **`SceneManager`** - Управління життєвим циклом сцен
  - Методи: `loadScene()`, `loadSceneAsync()`, `unloadScene()`
  - Властивості: `activeScene`, `sceneCount`

- **`Time`** - Таймер та управління часом гри
  - Властивості: `deltaTime`, `fixedDeltaTime`, `time`, `frameCount`, `timeScale`

- **`EngineSettings`** - Глобальна конфігурація двигуна
  - Налаштування: `Time`, `Physics`, `Math`, `Layers`, `Tags`, `Defaults`, `Quality`

### Основний цикл
- **`Application`** - Головний клас двигуна
  - Методи: `play()`, `pause()`, `stop()`, `requestRedraw()`
  - Властивості: `isPlaying`, `renderer`, `canvas`, `targetFrameRate`
  - Статичні: `current`, `version`, `isPlaying`

### Введення
- **`Input`** - Обробка клавіатури та миші
  - Методи: `getKey()`, `getKeyDown()`, `getKeyUp()`, `getMouseButton()`, `getMouseButtonDown()`, `getMouseButtonUp()`
  - Властивості: `mousePosition`

- **`KeyCode`** - Enum кодів клавіш
  - Поддержка: букви (KeyA-KeyZ), цифри (Digit0-Digit9), стрілки, Enter, Space, тощо

## 🧮 MATH - Математика

- **`Vector2`** - 2D вектор
  - Методи: `add()`, `subtract()`, `multiply()`, `dot()`, `cross()`, `normalized()`, `magnitude`, `distance()`
  - Статичні константи: `zero`, `one`, `up`, `down`, `left`, `right`

- **`Vector3`** - 3D вектор
  - Методи: `add()`, `subtract()`, `multiply()`, `dot()`, `cross()`, `normalized()`, `magnitude`, `distance()`
  - Статичні константи: `zero`, `one`, `up`, `down`, `left`, `right`, `forward`, `back`
  - Реалізує Zero-Allocation pattern через параметр `out`

- **`Vector4`** - 4D вектор
  - Методи: аналогічні Vector3
  - Використовується для RGBA кольорів та шейдерних параметрів

- **`Quaternion`** - Обертання в 3D просторі
  - Методи: `fromEuler()`, `toEuler()`, `slerp()`, `lerp()`, `conjugate()`
  - Статичні: `identity`
  - Усуває проблему Gimbal Lock

- **`Matrix4x4`** - Матриця 4x4 для трансформацій
  - Методи: `multiply()`, `inverse()`, `transpose()`, `getTranslation()`, `getRotation()`, `getScale()`
  - Статичні: `identity`, `zero`, `translate()`, `rotate()`, `scale()`
  - Формат: Column-major (як в OpenGL/Three.js)

- **`Bounds`** - Осесіметрична обмежувальна коробка (AABB)
  - Методи: `contains()`, `intersects()`, `setMinMax()`, `encapsulate()`
  - Властивості: `center`, `size`, `min`, `max`, `extents`

- **`Rect`** - Прямокутник у 2D просторі
  - Методи: `contains()`, `overlaps()`, `set()`
  - Властивості: `x`, `y`, `width`, `height`, `min`, `max`, `center`

- **`Ray`** - Промінь (origin + direction)
  - Методи: `getPoint()`

## 🎨 GRAPHICS - Графіка

### Базові класи
- **`Color`** - Колір у форматі RGBA (0.0 - 1.0)
  - Методи: `set()`, `copy()`, `lerp()`, `lerpUnclamped()`
  - Статичні константи: `white`, `black`, `red`, `green`, `blue`, `yellow`, `cyan`, `magenta`, `gray`, `clear`

- **`Mesh`** - Геометричні дані 3D меша
  - Методи: `setVertices()`, `setNormals()`, `setUVs()`, `setColors()`, `setTriangles()`, `recalculateNormals()`, `recalculateBounds()`, `clear()`
  - Властивості: `vertexCount`, `triangles`, `bounds`
  - Статичні: `CreateCube()`, `CreateSphere()`, `CreatePlane()`, `CreatePyramid()`, `CreateCylinder()`, `CreateCone()`, `CreateTorus()`, `CreateIcosahedron()`
  - Enum: `MeshTopology`, `IndexFormat`

- **`Texture`** - Базовий клас для текстур
  - Методи: `static load()`, `setFilterMode()`, `setWrapMode()`
  - Властивості: `width`, `height`, `filterMode`, `wrapMode`, `url`
  - Enum: `FilterMode` (Point, Bilinear, Trilinear), `TextureWrapMode` (Repeat, Clamp, Mirror)

- **`Texture2D`** - 2D текстура для матеріалів
  - Методи: `setPixels()`, `getPixels()`, `readPixels()`, `apply()`, `resize()`
  - Властивості: `width`, `height`, `format`, `mipmapCount`
  - Enum: `TextureFormat` (RGBA32, RGB24, Alpha8, ARGB32, RGB565, R16, RFloat, RGFloat, RGBAFloat)

- **`Shader`** - Представлення шейдера
  - Методи: `registerProperty()`, `findPropertyIndex()`
  - Властивості: `name`, `isSupported`
  - Статичні: `Standard`, `StandardSpecular`, `Unlit`, `Transparent`, `TransparentCutout`
  - Enum: `ShaderPropertyType` (Color, Vector, Float, Range, Texture, Int)

- **`Material`** - Базовий клас для матеріалів
  - Методи: `setColor()`, `getColor()`, `setFloat()`, `getFloat()`, `setTexture()`, `getTexture()`, `setVector()`, `getVector()`, `clone()`
  - Властивості: `shader`, `renderQueue`
  - Паттерн: `sharedMaterial` (спільна), `material` (копія для редагування)

- **`StandardMaterial`** - PBR (Physically Based Rendering) матеріал
  - Властивості: `albedoColor`, `albedoMap`, `metallic`, `smoothness`, `normalMap`, `normalScale`, `occlusionMap`, `occlusionStrength`, `emissionColor`, `emissionMap`, `renderMode`, `alphaCutoff`
  - Enum: `MaterialRenderMode` (Opaque, Cutout, Fade, Transparent)

### Допоміжно
- **`RenderingEnums`** - Enum для рендерингу

## 🎬 COMPONENTS - Компоненти

### Рендеринг
- **`Renderer`** - Базовий клас для всіх рендерів
  - Методи: `getSharedMaterial()`, `setSharedMaterial()`
  - Властивості: `enabled`, `shadowCastingMode`, `lightProbeUsage`, `reflectionProbeUsage`
  - Enum: `ShadowCastingMode`, `LightProbeUsage`, `ReflectionProbeUsage`

- **`MeshFilter`** - Зберігає Mesh для рендерингу
  - Властивості: `mesh`, `sharedMesh`

- **`MeshRenderer`** - Рендерує Mesh з матеріалом
  - Методи: успадковані від Renderer
  - Властивості: `materials`, `sharedMaterials`

- **`LineRenderer`** - Рендерує лінії
  - Методи: `setPositions()`, `setColors()`, `setWidth()`
  - Властивості: `positionCount`, `startWidth`, `endWidth`, `material`
  - Enum: `LineAlignment`, `LineTextureMode`
  - Типи: `GradientColorKey`, `CurveKey`

### Камери та освітлення
- **`Camera`** - Камера для рендерингу сцени
  - Методи: `worldToScreenPoint()`, `screenToWorldPoint()`, `worldToViewportPoint()`, `screenToRay()`
  - Властивості: `fieldOfView`, `near`, `far`, `aspect`, `orthographic`, `orthographicSize`, `depth`, `clearFlags`, `backgroundColor`, `viewport`
  - Статичні: `main`
  - Enum: `CameraClearFlags` (Skybox, SolidColor, Depth, Nothing)

- **`Light`** - Базовий клас для освітлення
  - Властивості: `type`, `intensity`, `range`, `color`, `shadows`, `shadowResolution`
  - Enum: `LightShadows` (None, Hard, Soft), `LightShadowResolution` (Low, Medium, High, VeryHigh)

- **`DirectionalLight`** - Спрямоване освітлення (сонце)

## 💥 PHYSICS - Фізика

- **`Collider`** - Базовий клас для колайдерів
  - Методи: `overlap()`, `raycast()`
  - Властивості: `enabled`, `isTrigger`

- **`BoxCollider`** - Прямокутний колайдер
  - Властивості: `center`, `size`

- **`Physics`** - Статичний клас для фізики
  - Методи: `raycast()`, `raycastAll()`, `overlapSphere()`, `overlapBox()`

- **`RaycastHit`** - Результат raycast операції
  - Властивості: `collider`, `distance`, `point`, `normal`, `transform`, `gameObject`

---

## 📦 SCENARIO - Сценарії

- **`Scenario`** - Клас для роботи зі сценаріями
  - Методи: `load()`, `getAssets()`, `getManifest()`

- **`ScenarioAssets`** - Управління активами сценарію

- **`ScenarioTypes`** - Типи та енуми для сценаріїв
  - Enum: `ScenarioCategory`, `ScenarioLoadState`
  - Типи: `IScenarioManifest`, `IScenarioAuthor`, `IScenarioLoadProgress`, `IScenarioContext`

## 🔗 Експортовані в index.ts

Всі класи експортуються через `src/engine/index.ts` для зручного імпорту:

```typescript
import { 
  // Core
  GameObject, Component, Transform, Scene, SceneManager,
  Application, Time, EngineSettings, Behaviour, ScriptableBehaviour,
  EngineObject, Input, KeyCode,
  
  // Math
  Vector2, Vector3, Vector4, Quaternion, Matrix4x4, Bounds, Rect, Ray,
  
  // Graphics
  Color, Mesh, Texture, Texture2D, Shader, Material, StandardMaterial,
  
  // Components
  MeshFilter, Renderer, MeshRenderer, LineRenderer,
  Camera, Light, DirectionalLight,
  
  // Physics
  Physics, RaycastHit,
  
  // Scenario
  Scenario, ScenarioAssets
} from '@engine';
```
